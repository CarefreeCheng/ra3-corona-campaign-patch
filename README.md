# 红警三 日冕 · 战役增强补丁

> 让**日冕（Corona）**下的**官方战役**拥有扩展模式的能力：卡住的关卡能过、战役里也能造扩展建筑、老建筑也能用扩展技能。

面向萌新的**一键安装包**，装完直接玩，不需要任何命令行操作。

---

## 这个补丁解决什么

日冕在**遭遇战**里做得很好，但一进**官方战役**就会遇到三类问题，本补丁逐个处理：

| # | 问题 | 补丁后的表现 |
|---|---|---|
| 1 | **战役卡关**：盟军第一关、苏联第八关打完目标不推进，永远过不去 | 自动补上被日冕"吃掉"的脚本标记，目标正常打勾、关卡正常推进 |
| 2 | **扩展建筑栏消失**：战役建造页只有原版建筑 | 战役里可以造胡杨防空、礁石岸防、重型火炮、宙斯盾、能量加特林、点防御塔、巨型要塞舰等扩展建筑 |
| 3 | **建筑科技缺失**：超级反应堆没有「预充能线圈」、高科少一堆升级 | 建筑一建出来（以及地图自带的老建筑，重新载入关卡后）就有扩展技能按钮 |

## 环境要求

- 红色警戒3 **1.12**（`Data\ra3_1.12.game`，版本号 1.12.3444.25830）
- 已安装 **日冕（Corona）** 3.2xx（本体即可，不需要额外 mod）
- Windows 10 / 11，32 位游戏进程
- 安装时需要**文件夹写入权限**（装在 D 盘一般直接可写；装在 Program Files 请用管理员运行）

---

## 安装

1. **完全退出日冕**（连启动器的悬浮窗一起退，任务管理器里不能有 `ra3_1.12.game`）
2. 双击 **`install.bat`**
   - 如果游戏不在默认路径 `D:\a game\Red Alert 3`，把**游戏文件夹拖到 `install.bat` 上**再松手
3. 看到 `安装完成` 即可

安装程序会自动完成：

- 备份原始 `xinput1_3.dll`（`.bak`）
- 准备 `ra3copilot.dll`（若本机没有，会从 [Ra3-Copilot 官方发布页](https://github.com/ProbiusOfficial/Ra3-Copilot/releases/tag/v1.2.0) 下载，不随包分发）
- 放入补丁组件（见下方"安装包结构"）
- 清理旧日志

**卸载**：退出游戏后双击 `uninstall.bat`，会还原 `xinput1_3.dll` 并删除所有补丁文件。

---

## 使用

1. 启动日冕，进入任意战役关卡
2. 进关后**等 20 秒左右**（启动器 -> 游戏 -> 自动注入 -> 打补丁，日志里能看到进度）
3. 之后：

- **卡关的关卡**：正常打，目标达成后会自动推进
- **扩展建筑**：建造页直接多出扩展建筑
- **建筑技能**：新建的建筑立刻有；**地图自带的老建筑需要"重新载入该关卡"**（读档或重进）才会变成扩展版

> 为什么老建筑要重载：建筑的可用技能在**它被创建的那一刻**就固定了。补丁在关卡载入时就把类型换成扩展版，所以只有"载入之后才出现"的建筑才能拿到完整技能。

## 已知限制

1. **秘密协议栏（侧边栏技能）无法补全**
   协议按钮来自玩家模板里预先定义好的固定清单，战役用的原版模板里没有扩展协议的位置。就算用内存接口把技能授予玩家（引擎返回成功），界面上也不会长出格子。这一项**不做**。

2. **敌方也会被替换成扩展版**
   这样是为了"工程师占领敌方建筑后同样有技能"。扩展版通常更强，如果你发现敌方单位/建筑行为异常，可以在 `docs/TECHNICAL.md` 里找到关掉它的办法。

3. **扩展版数值与原版不同**
   `_Enhanced` 是日冕扩展模式的完整版建筑（更强），不是原版数值 + 一个按钮。

4. **每局开头有约 20 秒的"未生效期"**
   注入是延迟 20 秒做的（太早注入会把游戏带崩），这段时间内建的建筑是原版。想要更快可以把 `bin\xinput_proxy.cfg` 里的 `delay_ms` 调小，但不建议低于 10000。

5. **只作用于单机战役**
   不触碰联机。

## 出问题了怎么办

三个日志文件，出问题时请一起提供：

```
<游戏目录>\Data\xinput_proxy.log     注入是否成功、延迟多少
<游戏目录>\Data\ra3fix_helper.log    建造页补丁、已放置建筑替换数量
<游戏目录>\Data\createhook.log       创建期类型替换，pairs 数量与命中记录
```

常见现象对照见 [docs/FAQ.md](docs/FAQ.md)。

## 原理（一句话版）

游戏启动时加载一个**同名 DLL 代理**（`xinput1_3.dll`，游戏本来就要加载它），代理先转给系统真身，再延迟 20 秒把 Ra3-Copilot 注入游戏进程，拿到它提供的内存读写与调用接口；然后用这个接口：

- 补上战役脚本被日冕跳过的标记（卡关）
- 把建造页的 CommandSet 换成扩展版（扩展建筑）
- 在原型查表函数 `0x007E4230` 上挂 7 字节跳转，把 `哈希(原版建筑)` 改写成 `哈希(扩展版建筑)`，让建筑**一出生**就是扩展版（建筑技能）

细节与偏移表：[docs/TECHNICAL.md](docs/TECHNICAL.md)

## 和 Ra3-Copilot 的关系

Ra3-Copilot 已经把"能不能做"证明了一遍，它的面板里有这些开关：

- 解除科技锁定 / 忽略前置科技 / **启用扩展模式科技**
- 战役目标调试器 + **一键修复剧情卡关**

本项目在它之上做了三件它没做的事：

| | Ra3-Copilot | 本项目 |
| --- | --- | --- |
| 卡关修复 | 需要在 overlay 里按 `INSERT` → 找到关卡 → 点目标 | 进关后自动，玩家不用操作 |
| 扩展建筑栏 | 需要在面板里手动开 `0x1D` | 启动自动开，且自动关掉会破坏科技树的 `0x1E` |
| 建筑科技（预充能线圈等） | 做不到（只改建造页与科技门） | 在建筑创建前换类型，建筑天生带扩展技能 |
| 部署 | 手动跑注入器 | 装一次，之后每次启动游戏自动生效 |

生态调查（2026-10-25，GitHub 检索 + 社区资料）：没有发现同类的"一键自动"实现。同期相关的仓库只有日冕地图 Lua 库（`dreamness-dnalm/Ra3CoronaMapLuaLib`）和实体名对照表（`LMaxRouterCN/RA3-CoronaMod-object-name`），都不涉及战役。
