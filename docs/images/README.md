# 截图放置说明

当前这三张是**占位图**（用脚本生成的说明卡）。要用真实截图替换，直接覆盖同名文件即可，README 里的引用不用改。

| 文件名 | 拍什么 | 建议 |
| --- | --- | --- |
| `build-page.png` | 战役里选中「苏联建造基地」，右侧建造栏能看到 **胡杨防空导弹系统 / 礁石岸防导弹要塞** 等扩展建筑 | 把鼠标停在其中一个扩展建筑上，让提示框出现，更有说服力 |
| `precharge.png` | 选中「超级反应堆」，鼠标悬停在红色升级图标上，**「预充能线圈 (F)」提示框**在画面里 | 这张最能证明"建筑科技"这一层 |
| `campaign-fix.png` | 苏联第 8 关（或盟军第 1 关）的目标列表，显示**目标已打勾、任务推进** | 若能用「击杀特使后目标变绿」的瞬间最好 |

要求：

- 分辨率 1280×720 或更高，PNG
- 别把游戏外的窗口拍进去（用游戏内截图，或 Alt+Enter 窗口化后截窗口）
- 单张控制在 1 MB 以内（GitHub 对图片大小没硬限制，但太大加载慢）

替换后重新提交即可：

```powershell
git add docs/images
git commit -m "docs: real screenshots"
git push
```
