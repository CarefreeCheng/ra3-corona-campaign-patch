# 常见问题

## 装了没反应，怎么办

按顺序看三件事：

1. **游戏是不是从 `RA3.exe` 启动的？** 必须用日冕启动器（`CoronaLauncher.exe`）或 `RA3.exe`。如果你从别的地方看到的 exe 名字不一样，先确认游戏目录里有没有 `Data\ra3_1.12.game`。
2. **日志有没有生成？** 进游戏后看 `你的游戏目录\Data\xinput_proxy.log`。
   - 文件不存在 → 代理没被加载，检查是不是装错目录（install.bat 会同时写根目录和 `Data\`）。
   - 有 `[init] ra3copilot(...) err=0` 但没别的 → copilot 起来了，但补丁没跑完，看 `ra3fix_helper.log`。
3. **是不是刚开局就看？** 补丁在"进关后约 20 秒"才动手。等一会儿再看。

## 为什么老建筑没有技能，新建的就有

命令栏在建筑**出生那一刻**就绑定了。地图自带的老建筑出生在补丁生效之前，所以它们还是原版。

**解决办法：重新载入那一关**（读档 / 重打本章）。重载后所有建筑都是补丁生效后创建的。

## 为什么敌人建筑也被改了

故意的。日冕的扩展版建筑更强，敌人也会跟着变强一点。这么做是为了让你用工程师占领敌方建筑之后，那些建筑同样带扩展技能（否则占领来的高科、反应堆全是"空壳"）。

如果你更希望"只改自己的"，改 `createhook.c` 里配对表的填充逻辑，或在 `PatchKey` 里加 owner 判断（需要从 `Thing` 反查，成本会高一些）。

## 会不会影响联机 / 存档

- **只做单机**。联机请勿使用。
- 不改存档文件，存档可以正常读写；但**补丁只在本次进程内生效**，换了进程（重开游戏）需要补丁重新跑一遍——正常启动游戏就会自动跑。

## 杀毒软件报毒

注入型工具（`LoadLibrary` 远程线程、`VirtualAllocEx`）天然容易被启发式引擎标记。本项目：

- 不联网上传任何数据（除了 install.bat 下载 `ra3copilot.dll` 那一步）
- 不修改游戏文件（只往游戏目录放 DLL）
- 全部源码在本仓库，可自行编译

如果被拦：把游戏目录加入白名单，或暂时关闭实时防护再安装。

## 提示 "game still running"

先**完全退出**日冕（连启动器悬浮窗一起），确认任务管理器里没有 `ra3_1.12.game` / `RA3.exe`，再运行 install.bat。

## 双击 install.bat 一闪而过

大概率是 DLL 正被占用（游戏没退干净）。install.bat 里已经加了 `tasklist` 检查和 `pause`，正常情况会停在报错页；如果完全没窗口，用"以管理员身份运行"再试一次。

## 怎么卸载

双击 `uninstall.bat`：还原 `xinput1_3.dll`（`.bak`）、删掉 `csprobe.dll` / `ra3fix_helper.exe` / `xinput_proxy.cfg` / `ra3dump_cs.exe`，日志一并清理。

注意：`ra3copilot.dll` **不会**被删（那是 Ra3-Copilot 的东西，你可能有别的用途）。

## 支持哪些版本

- 游戏：`ra3_1.12.game` **v1.12.3444.25830**（32 位）。版本不对时 copilot 会拒绝注入，补丁自然不生效。
- 日冕：3.2xx（实测 3.259）。扩展建筑清单在不同版本会变，但机制不变。
- 系统：Windows 10 / 11 64 位。

## 起义时刻能用吗

不能。日冕只基于原版 1.12，起义时刻是独立 exe（`RA3EP1.exe` + `ra3ep1_1.0.game`），数据、单位、脚本都不一样。

## 和 Ra3-Copilot 的 0x1D / 0x1E 开关冲突吗

不冲突，但**不要同时开**。本项目启动时自己会设 `0x1D=1` / `0x1E=0`；如果你在 overlay 里手动改了，以最后一次操作为准。

## 日志在哪

| 文件 | 内容 |
| --- | --- |
| `Data\xinput_proxy.log` | 代理加载、copilot 注入、helper 启动、存活检查 |
| `Data\createhook.log` | 配对表数量、hook 是否装上、每次哈希改写 |
| `Data\ra3fix_helper.log` | 开关状态、建造按钮替换数、已放置建筑替换数 |

发 issue 时把这三个文件（或它们的最后 30 行）贴上来，定位会快很多。

## 报错码参考

| 现象 | 含义 |
| --- | --- |
| `LoadLibraryW -> 0x0`, `err=126` | 路径含非 ASCII，或 DLL 被安全软件隔离 |
| `err=193` | 位数不对（64 位 DLL 注入 32 位进程） |
| 游戏启动即闪退，`c0000005` + 异常数据 `8` | DEP：往不可执行内存跳了（通常是 hook/桩的问题） |
| `err=5` 打开进程失败 | 权限不够（游戏以管理员运行时，补丁也要管理员） |
